# Kiva Agent

Kiva 是一个项目内自包含的 Pi Agent。Pi、Agent 资源、第三方插件声明和运行状态都由本仓库管理，不依赖全局安装的 `pi`。

## 环境

- Node.js 22.19 或更高版本
- pnpm 12.14（建议通过 Corepack 启用）

## 开始使用

```sh
corepack enable
pnpm install
pnpm start
```

首次启动后使用 `/login` 配置模型提供方。认证信息保存在被 Git 忽略的 `.kiva/agent/` 中。

也可以直接启动 Web UI：

```sh
pnpm web
```

启动后访问 `http://127.0.0.1:9495`（可通过 `PORT` 环境变量覆盖）。点击左侧“项目”标题旁的加号，可以浏览本机目录并注册项目；项目行依次是名称、新建会话加号和最右侧的三点菜单。点击名称或行内空白可折叠/展开会话，加号在该项目中新建会话（也可用 ⌘ / Ctrl + N），菜单内提供搜索会话和“移除”。“移除”只从页面隐藏项目，不删除文件、会话、工作区或配置，也不停止运行中的任务；重新导入同一目录即可恢复原项目及会话。模型、认证和 Kiva 扩展仍复用本仓库 `.kiva/agent/` 中的配置，各项目的会话保存在项目自己的 `.kiva/sessions/` 中。

会话三点菜单中的“查看 JSONL”可只读查看原始记录。弹窗默认展示记录关系和可展开的 JSON 字段，也可切换“原始文本”；空记录、损坏行和大文件预览截断会明确说明，不修改历史或启动 Pi。

输入框中的模型控件可同时选择模型和思考强度，点击“保存并应用”后写入安装目录的 `.kiva/agent/settings.json`，作为所有项目新会话的默认设置；在已有会话中保存也会应用到当前会话，其他已有会话不变。切换候选或取消不会修改设置，刷新与重启后仍能读取保存的默认值。

侧栏底部“设置”打开全局设置弹窗，包含外观、快捷键、模型、会话和关于。主题支持浅色、深色、跟随系统；字号、代码换行、思考/工具默认展开和常用快捷键等偏好仅保存在当前浏览器，同源标签页共享。默认仍是 Enter 发送、Shift+Enter 换行，也可选择 Command/Ctrl+Enter 发送。它们不修改 Pi 终端设置，不保存未发送草稿或附件。

设置里的默认模型只影响新会话；提供方接口定义和 API Key 分别保存到当前安装的 Pi 配置中，不回显已存密钥、不自动测试远程连接，也不启动会话。可以新增兼容接口及自定义模型；OAuth、高级认证或无法安全表示的配置只读保留。正在使用的提供方不能修改，其他任务不会被停止；保存后空闲运行时在下一次明确操作时安全加载新配置。配置冲突或失败会保留候选并支持重新加载后重试，“关于”提供不含密钥、路径和会话内容的诊断复制。

已有会话的输入框下方最左侧显示后端连接状态：连接中、已连接、重连中或已断开。它反映当前会话与 Kiva 后端的连接，不代表模型服务可用；尚未创建会话时不显示。

项目、会话、文件和差异使用独立 URL，可直接打开、刷新或通过浏览器前进/后退访问。例如 `/projects/<projectId>/sessions/<sessionId>/files?path=README.md` 查看这个会话的文件；`/projects/<projectId>/files` 则明确查看原项目目录。项目 ID 对应已注册目录，不是目录路径或项目名称。

新会话从创建时已提交的 HEAD 创建独立 Git worktree 和会话分支。原目录的暂存、未暂存、未跟踪和忽略文件（包括本地环境与依赖）不会被复制；依赖安装需要自行安排。会话中的 Pi、文件和差异都使用同一个独立工作区，界面显示目录与分支。同一项目的多个会话可以同时运行；打开另一个页面或关闭标签页不会停止任务。运行时容量由 `KIVA_WEB_RUNTIME_CAPACITY` 配置，默认 4；容量不足会明确提示。

旧会话仍可查看，通过“继续”创建继承对话的新会话和独立工作区。代码来自继续时的当前提交，不是旧对话当时的文件快照。非 Git 目录和没有首个提交的仓库可以浏览文件与历史；创建或继续执行前需要自行准备 Git 和初始提交，应用不会自动初始化、提交或改用原目录执行。

删除会话时，“同时删除对应工作区”默认勾选。只有空闲、归属明确且没有暂存、未暂存、未跟踪或忽略文件的工作区才能移除；有本地内容时需要先处理文件或取消勾选。取消勾选只把历史移入可恢复的回收站，保留工作区。分支始终保留；归档、页面切换和释放空闲运行时不会删除工作区。恢复历史不会重建已移除的工作文件，部分失败会保留可重试的操作状态。

安装目录 `.kiva/web-workspace.json` 保存版本化项目注册信息，迁移前保留备份；项目 `.kiva/web/sessions/` 保存空会话身份、工作区归属和删除状态。独立工作区默认位于安装目录同级的 `.kiva-worktrees/<安装标识>/<项目ID>/<会话ID>`，可通过 `KIVA_WEB_WORKTREE_ROOT` 指定根目录，已有工作区继续使用保存的位置。未发送文字和附件仅在当前标签页内存中按会话保留，应用内切换可恢复，刷新或关闭页面后不保留。

Web UI 使用 Next.js、shadcn/ui 和 Tailwind CSS。构建或运行生产版本：

```sh
pnpm web:build
pnpm web:start
```

也可以把参数直接传给 Pi：

```sh
pnpm kiva --help
pnpm kiva -p "解释这个仓库"
```

## 插件

通过项目命令安装和移除插件，命令会强制使用 Pi 的项目作用域：

```sh
pnpm plugin:add npm:some-pi-package@1.2.3
pnpm plugin:remove npm:some-pi-package
```

安装命令要求 npm 精确版本、完整 Git commit SHA 或仓库内的本地路径；未固定的远程来源会被拒绝。Git tag 也可能被移动，因此不能作为可复现版本。通用 `kiva install/remove` 入口同样被禁用，防止绕过项目作用域。插件声明写入 `.pi/settings.json`；下载内容分别位于 `.pi/npm/` 和 `.pi/git/`，不会提交到 Git。

## 目录职责

```text
bin/                    Kiva 命令入口
src/runtime.mjs         本地运行环境和 Pi 进程管理
agent/                  Kiva 自有的 Pi package
  extensions/           TypeScript 扩展
  skills/               按需加载的能力
  prompts/              Prompt 模板
  themes/               TUI 主题
.pi/                    可提交的项目级 Pi 配置
.kiva/                  不提交的认证、会话和缓存
```

`.pi/APPEND_SYSTEM.md` 定义 Kiva 的常驻行为原则。`agent/extensions/kiva.ts` 提供 `/kiva` 命令，用于确认项目扩展已加载。

## 开发检查

```sh
pnpm test
pnpm typecheck
node ./bin/kiva.mjs list --approve
```

终端 CLI 的工作目录固定为本仓库根目录。Web UI 通过 Pi RPC 在各会话的独立工作区中执行，可在界面中注册其他本机项目。
