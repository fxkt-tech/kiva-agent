# 技术方案

## 布局与状态
在现有持久 WorkspaceShell 中复用浏览器偏好，不增加独立的折叠状态副本。新增 `appearance.sidebarCollapsed: boolean`，默认 false；v1 逐字段兼容旧数据，不迁移版本、不在初始化时写入存储。header 和设置均更新同一字段，外观重置同步恢复默认。

扩展现有首屏偏好 bootstrap 与运行时 appearance 应用逻辑，以根节点 `data-sidebar-collapsed` 驱动桌面252/64px布局及品牌/图标呈现，避免水合前宽度闪动；不增加 body 的 hydration warning 豁免。首次客户端读取偏好前应限制项目列表 demand，避免已保存图标模式仍先读取所有展开列表。720px及以下覆盖桌面样式，沿用现有移动抽屉。

品牌 logo 使用现有图形并提供可访问的 SPA 首页链接；收起时品牌区居中显示 logo，展开按钮作为右侧边缘的独立控件，与 logo 错开；展开态仍在 header 右侧。左侧切换使用左右 Chevron，右侧输出气泡开关使用上下 Chevron。沿用现有图标、tooltip、按钮、Popover 和视觉 token，不引入新图标体系或弹窗库。

## 项目气泡与动作生命周期
WorkspaceShell 持有共享项目浏览气泡的打开状态；收起项目区仅有新增项目与更多两个按钮。使用 Base UI 的公开 hover 支持，在更多按钮右侧显示有界滚动的项目/会话分组列表，允许指针从按钮移入气泡及嵌套菜单；同时保留点击与键盘打开。关闭及布局切换不能丢失动作对话框。展开模式与移动端继续使用原有项目树；避免以两份数据控制器或隐式 DOM 移动实现展示切换。点击项目气泡外部可关闭，且保留点击目标的焦点；不改变右侧输出气泡禁止外部点击关闭的既有行为。Escape 优先处理当前嵌套菜单/对话框。

主导航保留原有 URL 作用域。当前项目沿用路由对应 active/archived/trash 集合，其他项目显示 active；气泡清楚标识集合。气泡内搜索只过滤该项目列表，不因浏览另一项目而写当前会话的 URL；原展开列表的 URL 搜索行为保持兼容。

不要为展开和图标模式各挂载一份 SessionRows。若现有 SessionRows 内部对话框会随 Popover 卸载，将动作状态与持久对话框提取为稳定控制器，再复用列表展示。保留独立集合页原有接口与行为。气泡/布局关闭后焦点回到当前存在的项目触发按钮，不能回到已卸载行；进行中的重命名、删除或 JSONL 查看必须保持有效。

## 数据边界
沿用 SessionListsProvider 的 project+collection 缓存、失效世代和并发限制。展开模式按原展开状态 demand；图标模式只在共享项目浏览气泡打开时为展开的项目组请求列表，关闭释放 demand。切换布局不重建会话主体，不调用运行/停止/队列命令，不重新定义资源身份。无后端 API 或持久化格式变更。

## 风险与验证
主要风险是 Popover 卸载导致对话框丢失、焦点回到旧 DOM，以及水合前偏好未知导致额外请求。实现先验证生命周期与首屏 demand，再做样式。用确定性本地 fixture 检查真实浏览器布局、刷新、跨标签页与移动抽屉；无需真实模型调用。可按前端提交整体回退，新偏好字段被旧版本安全忽略。

## 共享浏览气泡的展示边界
保留按 projectId 稳定挂载的 ProjectGroup/SessionRows，在共享气泡内按注册顺序建立 DOM 槽位，仅通过声明式 React portal 渲染各项目的标题、搜索与会话行。槽位使用稳定 ref 回调；动作与对话框状态留在原控制器，不能通过两份树或命令式搬动节点实现。使用 Base UI openOnHover（120ms）与 closeDelay（200ms）衔接指针路径；菜单、会话对话框及 shell 模态操作期间以局部交互标志保护悬停关闭。纯悬停不抢焦点，Escape 和显式关闭保留焦点回退。
