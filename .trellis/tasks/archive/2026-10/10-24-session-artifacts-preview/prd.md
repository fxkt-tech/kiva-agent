# 会话图片与 HTML 文件列表及预览

## 目标
用户无需翻找消息或目录，即可集中找到当前会话生成或引用的图片、HTML，并直接查看图片或运行交互页面。

## 已确认需求
- R1：仅列当前会话生成或引用的本地图片、HTML；不把整个工作目录作为会话产物，不包含上传附件。
- R2：HTML 必须支持 JavaScript 交互，以及 CDN 脚本、字体、图片和外部 API 联网请求。
- R3：用户已明确批准按最新交互方案开始实现；系统代理任务保持独立。
- R4：会话不显示固定文件侧栏。透明 header 的文件按钮默认关闭列表，点击弹出文件列表气泡，再点收回。每个文件支持默认弹窗预览、新标签页打开和气泡预览（替代原右侧预览）；预览气泡可拖动、调整宽高及关闭。

## 已批准首版范围
- R13：透明 header 保留在会话上方，右侧仅文件气泡切换按钮；列表气泡按图片 / HTML 分类并可筛选、刷新。预览气泡为不阻挡会话操作的浮动窗口，列表关闭不关闭已打开的预览气泡。三种预览方式复用内容能力，气泡移动/缩放不重新执行 HTML。桌面空间允许时，任一气泡打开会适度将消息和输入阅读区左移，全部关闭恢复居中；窄屏保留可读宽度，不强行左移。
- R5：从当前可见会话分支的成功结构化读写工具和消息明确文件路径建立关联；规范化路径去重，保留全部来源及最后引用时间。写入成功标记“生成/修改”，读取或消息链接标记“引用”。继承历史不得声称由新会话生成。
- R6：任意 shell 副作用不能可靠推断归属；工具输出或消息提供明确路径时可列为“引用”。不执行 shell 来发现文件，不以目录增量猜测归属。
- R7：用户明确要求放开工作区目录限制：当前会话明确生成或引用的本地图片、HTML，无论位于哪个目录，都可直接预览，不要求导入或复制。相对路径以会话记录的执行目录解析，绝对路径直接定位；HTML 的明确本地依赖可位于相邻、父级或其他目录。读取仍需由服务端会话来源确定精确文件身份，不能由客户端随意提交新路径。仅存在于远程 URL、消息内嵌 base64 或代码块中的内容首版不作为本地文件收录。HTML 允许远程依赖不等于远程网页收藏。
- R8：图片首版 PNG/JPEG/WebP/GIF/AVIF/SVG；SVG 只作为图片加载，不以内联 DOM 执行。HTML 支持 .html/.htm；支持内嵌 JS、CSS 及受控本地相对资源、HTTPS 外部资源和 API。外部 API 遵守对方 CORS；不承诺绕过跨域、第三方登录、HTTP 混合内容限制。
- R9：预览当前磁盘内容，明确显示“当前版本”；共享目录可能被其他会话修改，不承诺历史快照。删除、改名、工作区移除保留来源条目并显示不可用，不回退原项目目录。
- R10：历史记录按需重建；不启动 Pi、不写原始 JSONL。不完整记录、体积上限、损坏或读取失败必须显示完整性状态，不能伪装成空列表。
- R11：列表气泡可见或需要更新已打开预览元信息时才读取清单；选择预览才加载正文或大图。工具完成/回合结束合并刷新，避免每个 token 重扫历史；未打开预览不执行 HTML。
- R12：运行 HTML 与 KivA 身份、存储及业务接口隔离；仅授权当前页面及明确依赖，不暴露整个目录或自动提供 KivA 凭据。关闭或切换某个预览撤销该实例授权，来源定位失败给出明确信息；新标签页拥有独立预览授权，原会话切换或关闭不使其失效。

## 当前证据
- `web/features/files/workspace-browser.tsx`：文件页展示执行工作区，预览为文本。
- `web/server/scoped-transport.ts:169`：会话文件通过 resolveWorkspace 获取执行目录。
- `web/server/workspace-files.ts:10`：现有读取有路径、普通文件及 2 MB 文本限制，二进制不能用文本预览。
- `web/features/sessions/composer.tsx:23`、`web/server/runtime-hub.ts:190`：上传附件独立于落盘文件。
- `web/shared/runtime-types.ts`、`web/server/runtime-hub.ts:538`：有工具参数及结果，但没有产物注册表，UI history-index 也不是稳定来源 ID。
- `web/server/session-jsonl.ts`：原始 JSONL 预览会截断，不能作为完整产物索引来源。

## 验收标准
- A1（R1/R5/R6）：两个会话共享目录时，各自只列有自身来源证据的文件；读写失败不声称生成；shell 无路径证据不误归属。
- A2（R4/R8/R13）：header 点击弹出列表、再点关闭，不改变会话布局宽度；默认弹窗、新标签页、气泡预览均可查看图片及运行交互 HTML。预览气泡可拖动、缩放宽高、关闭，移动/缩放保留按钮/图表交互状态。
- A3（R9/R10）：刷新及重启可恢复清单；当前版本标识、文件缺失、已移除工作区、旧会话和不完整索引有真实状态。
- A8（R13）：会话始终没有固定侧栏/占位；透明 header 的单一按钮控制列表气泡。桌面打开气泡时阅读区左移、关闭全部气泡恢复居中，窄屏无横向溢出且会话可读。消息/runtime/composer 不重建，浮动预览不阻断消息输入和操作。
- A4（R4/R11/R12/R13）：列表与浮动预览生命周期独立；收回列表不重置预览，关闭预览只撤销自己的授权；默认弹窗关闭回到有效来源或 header 按钮焦点。切换会话不丢草稿、不影响运行，迟到响应不串会话；新标签页无 opener、可独立刷新且不被原会话切换关闭。
- A7（R7/R12）：工作区外绝对路径、明确引用的 ../ 相对路径图片及 HTML 可在三种模式预览；HTML 外部本地相对 CSS/ESM/JSON 可加载，路径别名正确归一化，未引用的其他文件仍不可通过接口或 token 随意读取。现有项目 files/diff 接口继续保留工作区边界。
- A5（R12）：恶意 HTML 无法读取父页面 DOM、存储、凭据或业务响应，不能执行 KivA 业务操作；依赖读取不能越过该预览的精确授权清单。
- A6（R8/R12）：外部跨域拒绝及依赖缺失可诊断，不添加万能代理；不能通过直接打开预览 URL 绕过 HTML 隔离。

## 不包含
