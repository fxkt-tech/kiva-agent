# Implementation boundary

The behavior gap is the absence of a session-owned artifact projection and executable, isolated preview hosts. This belongs in passive session history/resource services, the existing custom HTTP server, and the persistent conversation layout, rather than the project file tree or a model-process interception.

Backend owns scoped projection and provenance, shared contract, validated byte reads, capability assets/CSP and boundary tests. Frontend owns in-conversation right list, default dialog, side preview, independent new-tab host and UI tests. Main owns integration, specs and browser acceptance. No workers may commit, modify unrelated files, implement the proxy task, execute user HTML in the main DOM, or alter histories. Shared filesystem changes must be preserved.

Shared path-reading extraction must preserve existing files/diff semantics, demonstrated by existing workspace-files/diff tests. Changes in normal origin validation need regression checks for same-origin browser and supported no-Origin clients. Never open the real user project HTML for acceptance; use isolated temporary repositories and deterministic adapters.
